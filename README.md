## Опис
Vinyl Shop це онлайн-вітрина вінілових платівок для людей, які збирають музику на вінілі або тільки починають це робити. Тут можна зручно переглянути каталог з обкладинками, дізнатися деталі про кожну платівку, послухати уривки пісень, почитати відгуки інших покупців і залишити свій. Якщо потрібної платівки зараз немає, можна попросити застосунок повідомити, коли вона знову з'явиться в наявності.

## Ролі
- Гість: переглядає каталог, шукає платівки, фільтрує їх за жанром, виконавцем і ціною, відкриває картку платівки з детальною інформацією та відгуками, слухає уривки пісень. Може зареєструватися або увійти.
- Користувач: усе, що може гість, а також веде власний список бажаного, пише відгуки й ставить оцінки платівкам прямо на сайті, редагує та видаляє свої відгуки, підписується на сповіщення про появу платівки в наявності.
- Адміністратор: додає, редагує та видаляє платівки, виконавців і жанри, вказує посилання на обкладинки, змінює ціну й наявність (через API або адмінку Django), видаляє недоречні відгуки.

## Основний функціонал
- Каталог платівок з обкладинками, пошуком і фільтрами за жанром, виконавцем і ціною
- Картка платівки, яка відкривається після натискання на платівку в каталозі: велика обкладинка, ціна, наявність, трекліст, відгуки
- Реєстрація та вхід через JWT
- Список бажаного
- Кошик: додати платівку, змінити кількість, видалити, переглянути загальну суму (без оформлення замовлення і оплати)
- Відгуки та оцінки: авторизований користувач пише відгук і ставить оцінку через форму в картці платівки, а потім може відредагувати або видалити свій відгук
- Керування каталогом для адміністратора через API або адмінку Django

## Особливість проєкту
- Інтеграція з Deezer API: коли користувач натискає на назву платівки, застосунок шукає цей альбом у Deezer, показує список пісень і дає послухати 30-секундний уривок кожної з них.
- Email-сповіщення про наявність: у картці платівки, якої зараз немає, користувач може натиснути кнопку «Повідомити про наявність». Коли адміністратор позначить, що платівка знову є (через API або галочкою в адмінці Django), усі, хто натиснув цю кнопку, отримають лист на пошту. Листи надсилаються через Gmail, а якщо пошту не налаштовано, виводяться в консоль сервера.

## Як запустити бекенд
Потрібен Python 3.12 або новіший.

```bash
git clone https://github.com/darynab-stack/vinyl-shop-backend-final.git
cd vinyl-shop-backend-final
python -m venv venv
source venv/bin/activate        # на Windows: source venv/Scripts/activate
pip install -r requirements-dev.txt
python manage.py migrate
python manage.py loaddata demo  # тестові жанри, виконавці і 18 платівок
python manage.py createsuperuser
python manage.py runserver
```

Бекенд працює на http://127.0.0.1:8000, адмінка на http://127.0.0.1:8000/admin/.

### Справжні листи через Gmail (необов'язково)
Без цього кроку листи виводяться в консоль сервера.
1. У Google-акаунті увімкнути двоетапну перевірку і створити пароль застосунку на https://myaccount.google.com/apppasswords.
2. Скопіювати `.env.example` у `.env` і вписати адресу та пароль застосунку (16 літер без пробілів):
   ```
   GMAIL_USER=your_address@gmail.com
   GMAIL_APP_PASSWORD=your_16_letter_app_password
   ```
3. Перезапустити сервер. Файл `.env` не потрапляє в репозиторій.

### Сповіщення про наявність
| Метод | Адреса | Доступ | Опис |
|---|---|---|---|
| POST | `/albums/<id>/subscribe/` | користувач | Підписатися на платівку, якої немає в наявності. 201, або 400, якщо платівка вже є в наявності чи підписка вже існує |
| DELETE | `/albums/<id>/subscribe/` | користувач | Відписатися. 204, або 404, якщо підписки немає |
| GET | `/subscriptions/` | користувач | Мої підписки |

Приклад відповіді `GET /subscriptions/`:
```json
[{"id": 1, "album": 4, "album_title": "The Wall", "created_at": "2026-11-25T21:40:00Z"}]
```

Коли адміністратор змінює наявність платівки з «немає» на «є» (`PATCH /albums/<id>/` з `{"in_stock": true}` або галочкою в адмінці), кожен підписаний отримує лист, а його підписка видаляється.

### Відгуки
| Метод | Адреса | Доступ | Опис |
|---|---|---|---|
| GET | `/albums/<id>/reviews/` | усі | Відгуки платівки, нові спочатку |
| POST | `/albums/<id>/reviews/` | користувач | Написати відгук `{"text": "...", "rating": 1–5}`. Один відгук від людини на платівку |
| PATCH | `/reviews/<id>/` | автор | Змінити текст або оцінку |
| DELETE | `/reviews/<id>/` | автор або адміністратор | Видалити відгук |

Приклад відгуку:
```json
{"id": 3, "album": 4, "username": "daryna", "text": "Легендарний альбом!", "rating": 5, "created_at": "2026-11-25T21:45:00Z"}
```
